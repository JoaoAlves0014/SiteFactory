# Padrões de Qualidade e QA

1. **Checklist Técnico de Validação**:
   - [ ] Todos os arquivos do projeto existem (`index.html`, `main.css`, `app.js`, `favicon.svg`).
   - [ ] Metatags essenciais e título configurados.
   - [ ] Imagens ou mídias com textos alternativos (`alt`) e dimensões adequadas.
   - [ ] Interações funcionais sem erros no console (ex: botões de filtro, simuladores de financiamento).
   - [ ] Botão flutuante ou CTA de WhatsApp com formatação de link válida (`https://wa.me/...`).
   - [ ] Layout adaptável para telas menores que 768px.
