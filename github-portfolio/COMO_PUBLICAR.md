1. **`PROFILE_README.md`**: README de alto impacto para o repositório especial `JoaoAlves0014/JoaoAlves0014`.

## 📌 PARTE 1: Ativar seu Perfil de Alto Impacto no GitHub

### Passo a Passo:
1. Abra o navegador e acesse: [github.com/new](https://github.com/new)
2. No campo **Repository name**, digite exatamente:
   ```text
   JoaoAlves0014
   ```
3. O GitHub exibirá a mensagem de confirmação do repositório especial ✨
4. Marque como **Public**.
5. Marque a opção **Add a README file**.
6. Clique no botão verde **Create repository**.
7. Abra o arquivo [`PROFILE_README.md`](file:///c:/Users/joaop/OneDrive/Desktop/SiteFactory/github-portfolio/PROFILE_README.md) aqui no VS Code, copie todo o conteúdo.
8. No GitHub, clique no ícone de lápis (Edit) do `README.md`, cole o conteúdo copiado e clique em **Commit changes**.
9. Acesse seu perfil: 👉 [github.com/JoaoAlves0014](https://github.com/JoaoAlves0014)

---

## 🌐 PARTE 2: Publicar o Site no GitHub Pages (https://joaoalves0014.github.io)

### Passo a Passo:
1. Acesse: [github.com/new](https://github.com/new)
2. No campo **Repository name**, digite exatamente:
   ```text
   joaoalves0014.github.io
   ```
3. Marque como **Public**.
4. Não marque README (já temos todos os arquivos prontos).
5. Clique em **Create repository**.
6. No seu terminal aqui no VS Code, basta executar:
   ```powershell
   cd c:\Users\joaop\OneDrive\Desktop\SiteFactory\github-portfolio\site
   git init
   git add .
   git commit -m "Meu Portfolio Web"
   git branch -M main
   git remote add origin https://github.com/JoaoAlves0014/joaoalves0014.github.io.git
   git push -u origin main
   ```
7. Pronto! Seu site estará publicado gratuitamente e visível para o mundo em:
   👉 **https://joaoalves0014.github.io**
